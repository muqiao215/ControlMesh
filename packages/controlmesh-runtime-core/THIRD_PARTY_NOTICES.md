## CronSim 2.7

The cron grammar and calendar logic in `src/cron-schedule.ts` adapt behavior and
implementation patterns from CronSim by Pēteris Caune. Upstream: https://github.com/cuu508/cronsim.
TypeScript modifications implement explicit timezone resolution and bounded occurrence planning.
CronSim is used by the Python test oracle, not as a TypeScript runtime dependency.
